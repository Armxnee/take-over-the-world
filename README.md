# World Conquest

A real-time territory conquest game for Roblox: expand, trade, ally, betray and launch planes, boats and
missiles across a pixel map of the real world. Play it on Roblox (place 88696526459892).

- `src/shared` → ReplicatedStorage.Shared, `src/server` → ServerScriptService.Server,
  `src/client` → StarterPlayerScripts.Client. Sync with `py -I tools/bridge.py` + `tools/sync.lua` (docs/STATUS.md).
